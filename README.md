# Libra — Library Management System

A responsive, interactive Library Management System built with **HTML5, CSS3 and Vanilla JavaScript**. This project is designed as a Web Technology course project and runs entirely in the browser.

## Features
- Dashboard with live totals for books, available copies, active loans and members
- Book management: add, edit, delete and search
- Category filtering and ISBN/title/author search
- Member management: register, edit, delete and search
- Book circulation: issue books, set due dates and process returns
- Loan status indicators, including overdue status
- Editable administrator name
- Persistent browser storage using `localStorage`
- Responsive layout for desktop, tablet and mobile

## Technologies
- HTML5 for semantic page structure
- CSS3 for layout, styling and responsive design
- Vanilla JavaScript for application logic and interactions
- Browser LocalStorage for demo data persistence

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern browser.

No package installation or build step is required.

## Important note
This is a **front-end academic demonstration**. Data is saved in the browser's LocalStorage on the device/browser being used. It does not include a server, shared database, login authentication or multi-user synchronization. Do not use it to store sensitive real-world information.
